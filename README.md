# Iyunga School Portal

## Start the application

1. Install Python 3 if it is not already installed.
2. Double-click `start_server.bat`, or run `python server.py` in PowerShell.
3. Open http://127.0.0.1:8000 in a browser.

## Default login

- Username: `admin`
- Password: `1234`

The first server start creates `iyunga.db` automatically. All students, teachers, results and settings are stored in SQLite. Keep `iyunga.db` backed up because it contains the application data.
